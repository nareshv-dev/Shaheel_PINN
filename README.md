# PINN-Shaheel Notebook Repository

This repository contains Jupyter notebooks for Physics-Informed Neural Networks (PINN) applied to EV battery modeling and analysis.

## Notebooks

1. **PINN_V0_Audit_and_Verification.ipynb** - Initial audit and verification notebook
2. **DigitalTwin_V1_Scenario_Design.ipynb** - Digital twin scenario design for battery modeling
3. **PyBaMM_V1_Data_Generator.ipynb** - PyBaMM data generator for training datasets
4. **PyBaMM_V1_Data_Generator_CLEAN.ipynb** - Clean version of the PyBaMM data generator
5. **PINN_V1_Training_and_Validation.ipynb** - PINN training and model validation
6. **Cell_Localization_EarlyWarning_V1.ipynb** - Cell localization and early warning system
7. **PINN_EV_Battery_MultiPhysics.ipynb** - Multi-physics modeling of EV batteries

## Project Overview

This project focuses on developing Physics-Informed Neural Networks for predictive battery digital twins, including:
- Battery state prediction
- Thermal modeling
- Early warning systems for battery faults
- Multi-physics simulations

## Technologies Used
- Python
- PyTorch
- PyBaMM (Python Battery Mathematical Modeling)
- Jupyter Notebooks
- NumPy, Pandas, Matplotlib

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/nareshv-dev/pinn-shaheel-notebook.git
   ```

2. Install required dependencies:
   ```bash
   pip install torch numpy pandas matplotlib jupyter
   pip install pybamm
   ```

3. Run notebooks in Jupyter:
   ```bash
   jupyter notebook
   ```
