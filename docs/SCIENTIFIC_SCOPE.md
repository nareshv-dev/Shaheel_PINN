# Scientific Scope

- Saved Research Data is displayed from the project CSV and JSON artifacts.
- Interactive What-If playback is illustrative and deterministic, not a new
  electrochemical or neural-network solve.
- PC-MP-PINN records represent a single-particle experiment at the documented
  1.25C and 20°C test condition. They are not mapped to every pack cell.
- Stress is derived using the Cheng–Verbrugge operator from concentration.
- Signal anomaly ranking is retrospective detection; validated predictive
  early-warning lead time is not established because fault-onset timestamps are
  unavailable.
- B1 and B3 future-SOH inference is not enabled until the saved model contract
  is verified.
